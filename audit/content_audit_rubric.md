# 记录内容评分说明（content_audit_sheet.csv）

## 用途
审稿人要求对 action / reasoning 的内容本身给出评估，而不是只报结构合法率。
本表是从 R4（完整载荷、seed 42）的 1,000 条记录中用固定随机种子抽取的 100 条，
供两位评分人独立打分；完成后由作者计算一致率与 Cohen's kappa。

## 评分尺度（每格填 1 / 2 / 3）

### Action（防治建议）
- 3 = 具体且与所诊断病害匹配（可执行：药剂类别、栽培措施、清除病残体等）
- 2 = 方向正确但笼统（如"请咨询当地农业专家""加强管理"）
- 1 = 与诊断不匹配，或可能造成误导/危险

### Reasoning（推理依据）
- 3 = 明确引用了本次输入证据中的症状或候选概率，推理与诊断自洽
- 2 = 只复述诊断结论，未引用证据
- 1 = 与输入证据矛盾，或为套话/幻觉

## 评分规则
1. 两位评分人独立完成，不要互相讨论；不要看 DiagnosisCorrect 列。
2. 只根据表格里的证据字段和所给诊断判断，不查外部资料。
3. 允许留空（无法判断），在 Notes 写明原因。
4. 完成后把文件发回，不要改动其他列。

## 汇总方式（作者执行）
- 每人每个维度报告均值与分布；
- 两人一致率（完全相同 / 相差 ≤1）与 Cohen's kappa；
- 与结构合法率（100%）并列报告，说明内容质量与结构合法性是两件事。
